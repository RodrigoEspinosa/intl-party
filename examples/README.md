# IntlParty Examples

| Example | What it shows |
| --- | --- |
| [`nextjs-starter`](./nextjs-starter) | The documented Next.js setup from `intl-party nextjs --init`, on the published packages. Copy it with `npx degit RodrigoEspinosa/intl-party/examples/nextjs-starter my-app`. |
| [`react-standalone`](./react-standalone) | `@intl-party/react` in a Vite app, without Next.js |
| [`client-usage`](./client-usage) | The generated `@intl-party/client` package |

`nextjs-starter` isn't part of the pnpm workspace: it installs from npm, so it works on its own once copied.
