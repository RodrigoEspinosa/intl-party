# @intl-party/biome-plugin

## 1.11.0

### Minor Changes

- df9d790: New package: Biome GritQL plugins for IntlParty. `no-hardcoded-strings.grit` reports untranslated JSX text and `placeholder`, `title`, `aria-label`, `aria-description` and `alt` strings. `prefer-translation-hooks.grit` reports direct `i18n.t` usage. Requires Biome 2.5 or later. The README lists what the ESLint rules do that these plugins can't, including the `no-missing-keys` check.
