Make the documented Next.js setup work.

- `@intl-party/nextjs` now exports `createSetup(config)` and `useTranslations`, the API shown in the README and generated by `intl-party nextjs --init`. Neither existed before, so the Quick Start failed to compile.
- The main entry no longer breaks middleware and client bundles with `Can't resolve 'fs'`. Server-only dynamic imports are now skipped by webpack and Turbopack.
- `intl-party nextjs --init` writes a static middleware matcher (required by Next.js 16), generates `proxy.ts` on Next.js 16+, marks the example page as a client component, and no longer writes a `next.config.intl-party.js` that could not load.
